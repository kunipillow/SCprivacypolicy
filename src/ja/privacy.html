1. 本ポリシーについて

StratChart.com（以下「StratChart」または「私たち」）は、StratChart のアプリとこの Web サイトをご利用いただく際に私たちが取得する情報と、その利用方法について、このプライバシーポリシー（以下「本ポリシー」）で説明します。StratChart をご利用いただくことで、本ポリシーに同意したものとみなします。同意いただけない場合は、StratChart のご利用をお控えください。

2. 取得する情報

お問い合わせの際

アプリの Contact Us（お問い合わせ）フォームからお問い合わせいただいた場合、次の情報を取得します。

  • メールアドレス（返信のため。入力された場合のみ）
  • お問い合わせの種類と内容
  • サブスクリプション管理サービス（RevenueCat）が発行する匿名の利用者 ID と、サブスクリプションの登録状況
  • 端末の機種、OS のバージョン、アプリのバージョン

これらの情報は、お問い合わせへの返信と不具合の調査にのみ利用します。メールでお問い合わせいただいた場合は、メールアドレスとお問い合わせの内容を取得します。

アプリの利用時に自動的に取得する情報

  • 利用状況の統計（Google Firebase Analytics）：表示した画面、サブスクリプションの画面を開くなどの操作、端末とアプリの情報、アプリごとの識別子、IP アドレスから推定したおおよその地域（国など）。アプリの利用状況を把握し、改善するために利用します。広告識別子（IDFA）は使用しません。
  • クラッシュレポート（Google Firebase Crashlytics）：アプリが予期せず終了した際の、終了した箇所、端末の機種、OS のバージョン、アプリのバージョン、インストールごとの識別子。不具合の修正のために利用します。
  • アプリの正当性の確認（Google Firebase App Check。Apple の App Attest を使用）：通信が正規の StratChart アプリからのものであることを確認するための情報。データを不正な利用から守るために利用します。
  • 購入情報（RevenueCat）：匿名の利用者 ID と、App Store での購入およびサブスクリプションの履歴。サブスクリプションの提供のために利用します。

これらの情報を、氏名やメールアドレスと結び付けることはありません。

端末内にのみ保存する情報

設定（外観の設定など）と、ダウンロードしたチャートのデータは端末内に保存され、私たちに送信されることはありません。

3. 行わないこと

  • 他社のアプリや Web サイトをまたいだ追跡（トラッキング）は行いません。
  • 広告は表示しません。
  • 利用者の情報を販売することはありません。

4. お支払い

サブスクリプションの購入は Apple を通じて行われます。支払い情報は Apple が処理し、私たちがカード情報を閲覧することはできません。詳しくは Apple のプライバシーポリシーをご覧ください。

5. 利用している外部サービスと情報の保存場所

StratChart の運営には、次のサービスを利用しています。これらのサービスは、それぞれのプライバシーポリシーに従い、私たちに代わって情報を取り扱います。情報は米国のサーバーに保存されます。

  • Google（Firebase と Google Cloud）：プライバシーポリシー · Firebase のプライバシーとセキュリティ
  • RevenueCat：Privacy Policy（英語）
  • Apple：プライバシーポリシー

6. 情報の保存期間

お問い合わせの内容は、返信およびサービスの運営に必要な期間保存します。利用状況の統計とクラッシュレポートは、上記のサービスの保存期間の設定に従って保存されます。

7. 開示や削除のご依頼

お送りいただいたお問い合わせの内容について、開示や削除をご依頼いただけます。お問い合わせの際と同じメールアドレスからご連絡いただくか、該当するお問い合わせを特定できる情報をお知らせください。

8. 本ポリシーの変更

本ポリシーは、必要に応じて変更することがあります。変更した場合は、このページとアプリに新しい版を掲載し、冒頭の日付を更新します。

9. お問い合わせ

本ポリシーに関するご質問は、アプリの Contact Us（お問い合わせ）フォーム、またはメール（stratchart@gmail.com）でお問い合わせください。
